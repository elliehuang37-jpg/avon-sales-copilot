# AI 銷售者智慧行動助手 Sales Partner Copilot

每天自動整理銷售者應關懷的顧客、建議溝通內容、追蹤結果，讓數位能力較弱的銷售者也能用 AI。
可安裝成手機 APP（PWA），離線也能用；所有顧客資料只存在使用者自己的手機瀏覽器，不上傳任何伺服器。

適用：銷售領導人、第一線銷售者、教育訓練。

## 功能

| 分頁 | 內容 |
|---|---|
| ☀️ 今天 | 自動挑出今天該關心的顧客（預設 5 位，可調 3／5／8／12），完成進度環 |
| 💗 關心三步驟 | ① 選一句話（親切／專業／簡短、換一句、可直接改）② LINE 傳送／複製／電話／簡訊 ③ 記結果（有回覆／有下單／還沒回／改天再聯絡） |
| 👥 顧客 | 新增、搜尋、篩選（需要關心／VIP／新客）、往來紀錄、購買紀錄、CSV 匯入（支援 Big5、民國年） |
| 📈 成果 | 關心人數、回應率、成交筆數與金額、連續行動天數、每日長條圖、哪種關心最有效、一鍵 LINE 週報給領導人 |
| ⚙️ 更多 | 署名、預設語氣、大字模式、深淺色、安裝 APP、行事曆每日提醒（.ics）、教學、練習資料、領導人帶領指南、備份／還原 |

**✨ 請 AI 寫得更好**：把情境整理成去識別的提示詞（不含電話與全名），複製後打開 ChatGPT／Gemini／Claude 貼上即可。

## 關懷規則（優先順序）

| 原因 | 觸發條件 | 分數 |
|---|---|---|
| 🎂 生日祝福 | 7 天內生日、10 天內沒送過祝福 | 100（當天）／88−2×天數 |
| 📅 約好再聯絡 | 約定日期已到 | 95 |
| 🧴 補貨提醒 | 上次購買＋使用週期，到期前 7 天～過期 21 天，期間沒聯絡過 | 84−距到期天數 |
| 🌱 新客關懷 | 第一次購買後 3～14 天，之後沒聯絡過 | 72 |
| 🔁 再試一次 | 上次結果「還沒回」3～14 天前，連續未回少於 3 次 | 60 |
| 💌 喚回老顧客 | 超過 2 倍週期（至少 90 天）沒買、30 天沒聯絡 | 55（VIP +10） |
| 👋 好久不見 | 45 天沒聯絡 | 45（VIP +15） |

3 天內聯絡過的顧客只會因「生日」或「約好再聯絡」再次出現。

## 開發

```bash
node scripts/serve.js 5220        # 本機預覽 http://localhost:5220
node scripts/make-icons.js        # 重新產生圖示
node scripts/stamp-sw.js          # 改完任何檔案、commit 前執行，讓已安裝的 APP 拿到新版
```

`?demo=today`、`?demo=care`、`?demo=results` 會載入暫時的範例資料（不寫入儲存），用來產生 `screenshots/` 的安裝截圖。

# 雅芳銷售小幫手 AVON Sales Partner Copilot（第一階段・試點版）

給雅芳直銷商用的手機 APP（PWA）：每天整理該關心的顧客，跟著型錄檔期提醒分享和訂貨，話術幫你寫好並提醒合規用詞，一鍵 LINE 傳送，再記下結果。
所有顧客資料只存在使用者自己的手機瀏覽器，不上傳任何伺服器。

> ⚠️ 內含雅芳官方 Logo，**不要推到公開 GitHub repo**。正式上線請用公司網域，或經 IT 核准的位置。
> 通用版（中性品牌、公開）在 `../sales-partner-copilot`。

## 和通用版的差別

| 項目 | 雅芳版 |
|---|---|
| 品牌 | 官方 Logo 做 App 圖示（只縮放、不重繪）、Avon Red #E5004B、Lato＋中文黑體、預設大字 |
| 本期型錄 | 設定期別、開始日、訂貨截止日、每 14／21／28 天自動換期、本期主打、電子型錄連結；今天頁頂端顯示倒數，可一鍵「分享型錄」 |
| 品類 | 雅芳 7 大品類＋其他，各有預設回購週期（髮品 45、私密潔浴 30、體香／制汗 30、臉部保養 60、香水香氛 90、彩妝 90、保健食品 30 天），可逐筆修改；CSV 可依產品名自動判斷 |
| 新關心理由 | ⏰ 訂貨截止、🆕 新型錄上架、🎁 試用回訪、💐 節慶送禮（情人節、婦女節、母親節、七夕、父親節、中秋、聖誕、農曆新年） |
| 話術 | 語氣改成「姐妹聊天／正式有禮／一句就好」，帶入期別、截止日、主打、試用品、節日、品類貼心話 |
| 合規提醒 | 醫療效能、誇大身體機能、保證／絕對用語、招募收入暗示四類；打字時即時提醒，送出前再確認一次；「更多 → 話術用詞小提醒」有說明 |
| 用語 | 成交 → 訂貨、成果 → 業績、購買紀錄 → 訂貨紀錄 |
| 領導人指南 | 改成帶夥伴：陪伴安裝、型錄上架與截止的群組提醒、新人第 2 個月特別照顧 |

## 關心規則（優先順序）

| 原因 | 條件 | 分數 |
|---|---|---|
| 🎂 生日祝福 | 7 天內生日 | 100／88−2×天數 |
| 📅 約好再聯絡 | 約定日期已到 | 95 |
| 🧴 該回購囉 | 每個品類最近一次訂貨＋週期，到期前 7 天～過期 21 天 | 84−距到期天數 |
| ⏰ 訂貨截止 | 截止前 3 天內、本期還沒訂、熟客（訂過 2 次以上或 VIP）、半年內有訂貨 | 76～85 |
| 🎁 試用回訪 | 送試用後第 2～7 天 | 74 |
| 🌱 首購關心 | 第一次訂貨後 3～14 天 | 72 |
| 🆕 新型錄上架 | 開始日起 3 天內、半年內有訂貨、本期還沒聯絡過 | 70（VIP 76） |
| 🔁 再問一次 | 上次還沒回、3～14 天前 | 60 |
| 💌 喚回老顧客 | 超過 2 倍週期（至少 90 天）沒訂 | 55（VIP 65） |
| 💐 節慶送禮 | 節日前 3～14 天、一年內有訂貨 | 48（VIP 60） |
| 👋 好久不見 | 45 天沒聯絡 | 45（VIP 60） |

## 開發

```bash
node scripts/serve.js 5221                                        # 本機預覽 http://localhost:5221
powershell -ExecutionPolicy Bypass -File scripts/make-icons.ps1   # 由 icons/avon-logo.png 產生圖示
node scripts/stamp-sw.js                                          # 改完任何檔案後執行，讓已安裝的 APP 拿到新版
```

`scripts/avon-patch/` 是從通用版改成雅芳版的程式片段與 patch.js（`node scripts/avon-patch/patch.js <通用版 index.html 的副本>`），通用版有大改時可用來重新套版。

`?demo=today`、`?demo=care`、`?demo=results` 載入暫時範例資料（不寫入儲存），用來產生 `screenshots/`。
